# Demo presentation outline (7 slides)
1. Problem: manual pricing, lost requests, unread reviews in a 120-room Tirupati hotel
2. Solution: StayGenius AI, four roles, one platform
3. Architecture: HTML/CSS/JS, Flask, MySQL, scikit-learn, Gemini
4. Data model and double-booking protection
5. AI features: forecast, dynamic pricing, review NLP
6. GenAI features: reply drafts, insights, multilingual concierge, upsell, housekeeping schedule (bonus)
7. Live demo path: guest books > concierge raises towel request > front desk check-in/out + invoice > manager approves prices and replies to review > admin dashboard
